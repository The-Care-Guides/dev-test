# Order Service — Interview Test

This repo contains two implementations of the same theater ticketing backend. Pick one based on your stack.

| Implementation | Stack | Setup |
|---|---|---|
| [`java/`](java/) | Java 17, Spring Boot, H2 | `./mvnw spring-boot:run` |
| [`nodejs/`](nodejs/) | Node.js 18+, Express, SQLite | `npm install && npm run db:setup` |

The task is in `TICKET.md` inside each folder — it's the same task for both.
